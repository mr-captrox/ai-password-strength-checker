## ✨ Features

- **Real-Time Evaluation:** Assesses password strength instantly as you type.
- **Dynamic Progress Bar:** Visual indicator changing from red (weak) to green (very strong).
- **Password Rules:** Clear checklist showing which security rules have been met.
- **AI Security Suggestion:** Smart feedback designed to help improve your password step-by-step.
- **Password Generator:** One-click generation for a secure, 14-character password.
- **Toggle Visibility:** Easily show or hide your password with an intuitive eye icon.

## 💻 Technologies Used

- **HTML5:** Semantic structure of the web page.
- **CSS3:** Modern styling, flexbox layouts, responsive design, and smooth color transitions.
- **JavaScript (Vanilla):** Logic for live password evaluation, random secure password generation, and DOM manipulation.
- **FontAwesome:** Icons for intuitive UI elements.

## 🚀 Getting Started

To run the project locally, simply clone the repository and open the `cs/index.html` file in your preferred web browser. No external dependencies, servers, or build tools are required!

```bash
# Clone the repository
git clone https://github.com/mr-captrox/ai-password-strength-checker.git

# Navigate to the project directory
cd ai-password-strength-checker

# Open the HTML file in your browser
open cs/index.html
```
