# AI Password Strength Checker

An elegant, browser-based password strength checker that provides real-time feedback and AI-driven security suggestions. This tool evaluates passwords based on length, character types (uppercase, lowercase, numbers, special characters), and calculates an overall score.

## Features

- **Real-Time Evaluation:** Assesses password strength as you type.
- **Dynamic Progress Bar:** Visual indicator changing from red (weak) to green (very strong).
- **Password Rules:** Clear checklist showing which security rules have been met (e.g., minimum 8 characters, uppercase, lowercase, numbers, special characters).
- **AI Security Suggestion:** Smart feedback to help improve your password.
- **Password Generator:** One-click secure password generation.
- **Toggle Visibility:** Show or hide password with an intuitive eye icon.

## Technologies Used

- **HTML5:** Structure of the web page.
- **CSS3:** Styling, responsive design, and smooth transitions.
- **JavaScript (Vanilla):** Logic for password evaluation, random generation, and DOM manipulation.
- **FontAwesome:** Icons for UI elements.

## Getting Started

To view the project, simply clone the repository and open the `cs/index.html` file in your preferred web browser. No external dependencies or build tools are required!
